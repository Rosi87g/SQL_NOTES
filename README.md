## Notes

- The complete updated notes are available in the `01 - docs` folder.
- The notes contain the concepts, explanations, examples, practice questions, and interview questions.
- The SQL folders contain the corresponding runnable practice scripts.
- Chapters that are mainly conceptual or setup-focused do not require a separate SQL script.

## How to Run

1. Open **MySQL Workbench**.
2. Open the SQL script for the chapter you want to practice.
3. Run the script from top to bottom.
4. Execute the queries individually when you want to observe each concept and its result.
